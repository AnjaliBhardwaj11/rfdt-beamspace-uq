# Installation and Usage

This guide provides full environment setup and execution steps for the RFDT beamspace UQ pipeline.

## 1. System Requirements

- OS: Ubuntu 20.04+ (Ubuntu 22.04 recommended)
- GPU: CUDA-capable GPU recommended (RF-3DGS suggests 24 GB VRAM for training)
- CUDA Toolkit: 11.7 or 11.8 recommended for RF-3DGS training
- Conda: recommended for isolated environments

## 2. Create the Conda Environment

The environment used for the latest runs is below. If you need strict RF-3DGS compatibility, see their README for Python 3.8 guidance.

```bash
conda create -n rf-3dgs python=3.10.19
conda activate rf-3dgs
```

## 3. Install Dependencies

From the repository root:

```bash
pip install -r requirements.txt
```

If you prefer to pin versions explicitly (based on the tested environment), you can install key packages directly:

```bash
pip install numpy==1.26.4 scipy==1.15.3 matplotlib==3.10.8
pip install tensorflow==2.15.1 sionna==0.19.2 plyfile==1.1.3
```

> Note: RF-3DGS upstream notes primary compatibility with Sionna 0.19.1. This repo was tested with 0.19.2.

## 4. RF-3DGS Prerequisite (PLY Generation)

This pipeline expects a RF-3DGS point cloud, generated by their training pipeline.

- RF-3DGS repository: https://github.com/SunLab-UGA/RF-3DGS
- RF-3DGS paper: https://arxiv.org/abs/2411.19420

Typical RF-3DGS output path:

```
RF-3DGS/output/<experiment>/point_cloud/iteration_<N>/point_cloud.ply
```

Reference point cloud used in our runs:

- [point_cloud.ply](https://indianinstituteofscience-my.sharepoint.com/:u:/g/personal/anjalib_iisc_ac_in/IQBWNQELjDoJRaUzx2iTrlGZASrUdmeeQKxQlhlXImeo-dY?e=OgblRk)

Download the PLY locally and set an absolute path in `uq_config.json` under `forward.ply_path`.

## 5. Prepare Configuration

Copy the example config and update paths:

```bash
cp uq_config.example.json uq_config.json
```

Update these fields:

- `forward.ply_path`: path to the RF-3DGS point cloud
- `sionna.scene_xml`: Sionna scene file (Mitsuba-style XML)
- `forward.freq_hz`, `forward.tx_pos_m`, `forward.array`: must match the RF-3DGS training settings
- `preprocess.*`: optional settings for visual/RF dataset generation

## 6. Optional RF-3DGS Preprocessing

If you need to regenerate RF-3DGS training datasets, use the preprocessing scripts below. You must provide the mesh assets referenced by the scene XML (copy RF-3DGS `meshes_d` into `scenes/meshes_d`, or update the paths).

Visual dataset (Blender):

```bash
blender -b -P scripts/preprocessing/generate_visual_dataset.py -- --config uq_config.json
```

RF dataset from Sionna:

```bash
python scripts/preprocessing/sionna_onetx.py --config uq_config.json --ideal --spectrum-type mpc --output-dir dataset_ideal_mpc
```

Prepare multi-TX dataset structure:

```bash
python scripts/preprocessing/prepare_rf_data_multx.py --config uq_config.json --rf-root dataset_custom_scene_ideal_mpc_with_object_txmulti
```

## 7. Run the Pipeline

All commands should be run from the repository root:

```bash
python scripts/run_rfdt_rendering.py --config uq_config.json --output-dir outputs
python scripts/run_alignment_evaluation.py --config uq_config.json --rfdt outputs/rfdt_beam_energy_grid.npy --output outputs/sionna_beam_energy_grid_aligned.npy
python scripts/run_ut_propagation.py --config uq_config.json --gt outputs/sionna_beam_energy_grid_aligned.npy --output-dir outputs
python scripts/run_variance_validation.py --config uq_config.json --out-dir outputs/ut_mc_geometry_results
python scripts/plot_rfdt_vs_sionna_comparison.py --config uq_config.json --rfdt outputs/rfdt_beam_energy_grid.npy --sionna outputs/sionna_beam_energy_grid_aligned.npy --save-dir outputs/plots
```

## 8. Smoke Tests

Quick validation of dependencies, config paths, and output artifacts:

```bash
python scripts/run_smoke_tests.py --config uq_config.json --output-dir outputs --check-outputs
```

## 9. Troubleshooting

- **Mismatch between RFDT and Sionna**: verify `forward.freq_hz`, `forward.tx_pos_m`, and `sionna.scene_xml` match the RF-3DGS scene used for training.
- **Sionna API errors**: use the version recommended by RF-3DGS (0.19.1) or upgrade carefully.
- **CUDA errors**: ensure CUDA 11.7/11.8 is installed system-wide before installing PyTorch.

For RF-3DGS training issues, consult their README and troubleshooting section.
