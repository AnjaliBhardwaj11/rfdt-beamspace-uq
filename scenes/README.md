# Scenes

This folder contains Sionna/Mitsuba XML scenes used for preprocessing and alignment.

- room_with_cube.xml is derived from the RF-3DGS scene and expects mesh assets in scenes/meshes_d.

To use this scene:
- copy the RF-3DGS meshes_d folder into scenes/meshes_d, or
- edit room_with_cube.xml to point to your mesh locations.
